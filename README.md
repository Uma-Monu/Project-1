# Project-1
**Uber Eats Bangalore Restaurant Intelligence &amp; Decision Support Systems
**

This project analyzes Uber Eats restaurant and order data. The objective is to clean raw data and store data in SQL databases, and answer business questions using SQL queries. The project helps understand customer preferences, restaurant performance, ratings, costs, cuisines, and ordering trends. Methods used  are Python, Pandas, JSON, and SQLite in uber eats restaurant and order data. This project provides useful insights for restaurant owners and food delivery businesses.
